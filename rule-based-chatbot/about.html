About this project

Why NextStep exists

This project started as a CodSoft AI Internship task: "build a chatbot that responds to user inputs based on predefined rules, using if-else statements or pattern matching." Rather than ship a bare command-line bot, the goal was to show that a rule-based engine — no machine learning, no API calls — can still power something genuinely useful when it's wrapped in a real application.

NextStep is that application: a resume and interview prep hub where RuleBot, the chatbot, acts as a guide rather than a novelty. It answers career-prep questions, quizzes users with mock interview questions, and is available everywhere as a floating widget — while the rest of the site provides deeper, structured tools (a bullet-point analyzer, an action-verb bank, flip-card question practice) that a chatbot alone can't do well.

How the engine works

Rule-based, not machine learning

Every message typed into RuleBot is tested, in order, against a list of intents. Each intent owns one or more regular expressions. The first pattern that matches wins, and its handler function produces a response — some handlers also extract data straight from the sentence (like pulling a name out of "my name is Alex", or parsing numbers out of a math expression).

There's no model, no training data, and no network request involved in generating a reply — which is why matches resolve in well under a millisecond. Toggling "show pattern trace" on the chat page reveals the exact regex and intent behind any given reply.

Tech stack

Deliberately dependency-free

HTML5

Five static, semantic pages — no server or build step required.

CSS3

One shared design system: custom properties, grid, flip-card 3D transforms.

Vanilla JS

Rule engine, DOM rendering, and interactivity — zero frameworks, zero build tools.

Regex

The entire NLP layer: pattern matching, entity extraction, and intent routing.
