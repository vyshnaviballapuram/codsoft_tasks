# CodSoft Project Portfolio

This repository contains three independent projects, each in its own subfolder.

| Project | Description | Stack |
|---|---|---|
| [`face-recognition-system/`](./face-recognition-system) | Full-stack face detection and recognition system — SSD detector with a swappable LBPH/ArcFace recognition engine, supporting image, video, and webcam input | OpenCV, Streamlit |
| [`movie-recommendation-system/`](./movie-recommendation-system) | Content-based movie recommender — search a film, get 5 similar picks ranked by genre, plot, cast and director | Flask, scikit-learn, TF-IDF, Docker, deployed on Render |
| [`rule-based-chatbot/`](./rule-based-chatbot) | NextStep — rule-based career preparation platform with an ATS-friendly resume builder, interview chatbot, and placement resources | HTML, CSS, JavaScript |

Each subfolder has its own README with setup instructions, project structure, and usage details.

## Getting Started

Clone the repo, then move into whichever project you want to run — each is self-contained.

```bash
git clone https://github.com/<your-username>/CODSOFT.git
cd CODSOFT/<project-folder>
```

Refer to each project's README for its specific setup steps.
